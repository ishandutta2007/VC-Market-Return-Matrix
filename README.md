# VC-Market-Return-Matrix

## Multi-Market Venture Capital Fund Returns Matrix

A comprehensive overview of publicly verifiable fund performance data (Net Internal Rate of Return [IRR] and Total Value to Paid-In [TVPI]) for top multi-market venture capital firms. 

Data is aggregated from institutional Limited Partner (LP) disclosures, including [CalPERS](https://www.calpers.ca.gov) and the [University of California Regents (UCOP)](https://www.ucop.edu).

## Key Insights & Structural Notes

* **Vintage Impact:** Venture capital performance relies heavily on fund vintage years. Older cohorts (e.g., mid-2010s) demonstrate mature, realized performance, whereas 2020–2022 vehicles reflect tech ecosystem adjustments and unrealized paper valuations.
* **Reporting Granularity:** Top-tier firms do not report unified global returns. Instead, performance metrics are tracked via isolated, region-specific fund entities facing institutional LPs.
* **Geopolitical Restructuring:** Legacy cross-border funds, including Sequoia Capital and GGV Capital, have executed complete operational splits into standalone regional firms (such as HongShan, Peak XV, and Granite Asia).
